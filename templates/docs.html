Perion Auth API

Add password + TOTP two-factor authentication to your app in minutes.

Base URL

https://perion-auth.onrender.com/api/v1

Authentication

Every request must include your API key in the X-API-Key header.

X-API-Key: per_live_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
⚠️ Never expose your API key in client-side code. Only call the API from your backend server.

Endpoints

GET/health

GET /api/v1/health

Check that the service is running. No API key required.

{
  "status": "ok",
  "service": "Perion Auth",
  "version": "1.0"
}

POST/signup

POST /api/v1/signup

Create a new user account. Returns a QR code the user scans with Google Authenticator.

{
  "email": "user@example.com",
  "password": "minimum8chars",
  "name": "John Doe"
}

Response:

{
  "success": true,
  "user_id": 42,
  "email": "user@example.com",
  "qr_code": "data:image/png;base64,...",
  "uri": "otpauth://totp/...",
  "secret": "JBSWY3DPEHPK3PXP",
  "backup_codes": ["12345678", ...]
}

POST/login

POST /api/v1/login

Step 1 of login. Verify email + password.

{
  "email": "user@example.com",
  "password": "theirpassword"
}

If 2FA is enabled, you get back:

{
  "success": true,
  "totp_required": true,
  "user_id": 42,
  "message": "Call /api/v1/verify with the 6-digit code"
}

POST/verify

POST /api/v1/verify

Step 2 of login. Verify the 6-digit TOTP code (or a backup code).

{
  "email": "user@example.com",
  "code": "482913"
}

Response:

{
  "success": true,
  "session_token": "abc123...",
  "user_id": 42
}

GET/me

GET /api/v1/me

Get info about the currently signed-in user.

Authorization: Bearer <session_token>

POST/logout

POST /api/v1/logout

Invalidate a session token.

Authorization: Bearer <session_token>

Quick Start (JavaScript)

const API = 'https://perion-auth.onrender.com/api/v1';
const KEY = 'per_live_your_key_here';

async function signup(email, password, name){
  const res = await fetch(`${API}/signup`, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'X-API-Key': KEY
    },
    body: JSON.stringify({ email, password, name })
  });
  return res.json();
}

Quick Start (Python)

import requests

API = "https://perion-auth.onrender.com/api/v1"
KEY = "per_live_your_key_here"

def signup(email, password, name):
    r = requests.post(f"{API}/signup", 
        headers={"X-API-Key": KEY},
        json={"email": email, "password": password, "name": name})
    return r.json()
